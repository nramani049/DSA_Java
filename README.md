# DSA Java

Welcome to the Data Structures and Algorithms in Java repository.

This repository currently contains:

- `sum_array.java`, a Java example for summing array values.
- `sum_array.class`, the compiled version of the example.
- `BCA_JAVA.zip`, an archive of the related Java basic program material.

## Running the example

Compile and run the Java source with:

```text
javac sum_array.java
java sum_array
```

Thank you for visiting this repository. The files are provided for MCA coursework, practice, and learning.
